# indian-bikes-analysis-powerbi
Power BI dashboard analyzing Indian bike brands, pricing, mileage, engine capacity, top speed, GST rates, and bike segments using interactive visualizations.

## Project Overview
An interactive Power BI dashboard designed to analyze the Indian motorcycle market across different brands, price segments, performance metrics, and model years.

## Objectives
- Compare bike pricing across budget, mid-range, and premium segments.
- Analyze mileage and fuel tank capacity.
- Compare engine capacity and top speed.
- Evaluate brand-level overall scores.
- Explore bike model counts and pricing trends.

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis

## Dashboard Pages
1. **Market Overview** — Key metrics and segment-level insights.
2. **Pricing & Brand Analysis** — Brand pricing and bike distribution.
3. **Performance Analysis** — Mileage, fuel capacity, engine capacity, and top speed.
4. **Market Trends & Insights** — Model-year trends, GST rates, and brand comparisons.
